# Topbar clock update

The logged-in SentinelSOC topbar now follows the supplied reference layout:

- Dedicated purple-bordered live clock card immediately after the search box.
- Clock displays HH:MM:SS with AM/PM and updates every second.
- Current date is shown below the clock.
- Separate calendar/date block follows the clock with Today + full date.
- LIVE status, notifications, and admin profile remain on the right.
- Existing dark-default theme behavior is preserved.
